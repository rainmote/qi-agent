- 排队和插话现在显示等待状态，按队列 ID 区分各次输入；成功接收后由正式用户消息接替，不按正文去重。
- 取消、失败或工具终止后保留未发送文字、附件、复制按钮和下载入口；快照恢复与四种对话展示模式保持一致。
