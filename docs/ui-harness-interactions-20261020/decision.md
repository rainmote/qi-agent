# 具名差异与最小范围决策

用户允许学习更合理的官方设计。本轮已把可直接接线的前端缺项做成真实功能；不要求为了继续局部改造先批准品牌或后端迁移。**严格像素仍blocked，无残差豁免。**

| 区域 | 现有具体差异及原因 | 最小后续决策/工作 |
| --- | --- | --- |
| 快捷键目录 | qi的11项导航及固定输入说明；官方另有会话重命名/分叉/归档、字号、终端、分栏/全屏、刷新/关闭页面等上下文操作。qi相关会话功能有菜单，但未扩全局破坏性键，也没有终端/页签系统 | 菜单操作可另行逐项接安全上下文；终端/面板需真实能力，不放假动作。11项不能称官方完整目录 |
| 快捷键窗口/编辑 | 同480×600结构，qi有应用分组标题、可见焦点环、逐层返回和独立说明；官方行上直接内嵌紧凑录键，设置仍留底层；qi关闭设置后打开速查并正确返回 | 普通前端可继续对齐行结构/文案/焦点呈现；这些不是后端障碍，本轮只完成有用的最低改造，没有签发像素通过 |
| 链接偏好 | 官方网页侧栏/新标签选项仅在内建browser可用时出现；文件链接独立打开文件栏。qi没有远程浏览器，文件偏好提供现有授权预览或原生content新标签 | 保持外站新标签；如需官方网页侧栏，先决定真实浏览器能力与安全边界，不能用远程iframe/proxy或放宽CSP假装等价。Markdown等可由浏览器下载 |
| 设置分区 | qi General/Models/Plugins/Tools/Workspaces是真实能力；官方分区由已注册slot决定，本次实际参考显示General/Models/Built-in plugins/Agent presets。源配置文件/账户/归档/遥测等没有完整qi Web链路 | 可继续逐项设计真实入口；不加空分区、不把Host配置写入伪装成本地偏好 |
| 身份、预设、权限 | 保留qi标志/真实Web版本、标准/创造/生产只读真实预设、当前会话权限；与官方身份、标准/PTC/极简/创造及新会话默认权限语义不同 | 用户已要求保留qi能力。本轮不新增Host权限系统、不改名冒充PTC。若以后要求能力等价，应另定真实迁移范围 |
| 栅格残差 | 旧深色首页输入卡、permission/workspace/model菜单及320模型菜单、明暗设置三主题图标与字号步进器13处；新增设置菜单/选择器也无消除证明 | 仍是未解决的具名视觉差异，不能全部归因后端、动态内容或噪声；不继续无收益参数试探，不改阈值为通过 |
| 动态及夹具 | 本轮官方底层新会话/设置与qi会话夹具、时间/实际后端临时会话ID不同 | 原图/元数据完整保存，只作为功能实拍和非零差异证据；不以排除背景掩盖静态不一致 |
