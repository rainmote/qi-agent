# 需要服务配置的桌面功能选择

本地 Browser、PTY、Python/Office/pnpm 运行时继续实施，不以这些服务选择为前置条件。
不创建凭据、不复制 Harness 账号或签名身份，不以占位配置伪称功能可用。

| 功能 | 当前可交付的本地行为 | 真正需要决定的最小项 |
| --- | --- | --- |
| Platform 账号 | 保留 qi 现有 Provider/API 配置，不显示可用的 Harness Platform 登录 | 采用现有 qi 的 API 配置，或提供 qi 自有账号服务的 HTTPS 基址、OAuth/PKCE 客户端标识及精确回调/许可 origin；没有对应服务就不能实现真实账号登录 |
| Usage/Top-up/账号文档 | 本地帮助可随包；当前账号用量/充值后端不存在 | 是否只提供随包帮助；若要嵌入服务，需精确 HTTPS 页面 origin、公开页面路径及服务实际支持的认证方式。不得把 Provider 密钥或第三方账号 Cookie 注入页面 |
| 自动更新 | 本地 ad-hoc 包不接更新源、不安装更新；版本可查 | 保持本地包，或在后续单独授权后配置自有更新服务地址、平台发布身份和签名校验公钥。生成/读取私钥、Apple 公证、签约和发布均需明确授权，不由本任务创建 |

这些选择不影响本地聊天、项目管理、审批或离线资源。远程服务未配置时应明确显示不可用，
不通过隐藏状态、跳过测试或伪造账号使总验收变绿。其他平台与实际安装升级仍需各自构建/验收。
