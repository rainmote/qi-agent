# 桌面侧栏浏览器

参考官方 Harness `687f282e8625c6b8d11ff58211a90524be2e4317` 的 `apps/desktop/src/browser-guests.ts` 与 `packages/client/ui-sidebar-browser/README.zh.md`。本轮只读同版本源码；未新增参考实拍。

桌面菜单或会话工具栏打开浏览器。每个会话保留页签；只持久化地址和标题，重启后需明确恢复网页。HTTP(S) 页面使用与主应用分开的 WK 非持久工作区数据存储，工作区内共享，工作区间隔离。浏览器不是 LCU 的自动化表面，网页内容不会自动进入模型上下文。

主应用仅获得有限、来源校验的浏览器导航通道，无 shell、任意文件或 Tauri invoke 权限。每个原生视图持有不可猜测的工作区/运行代次租约；重复获取用独立请求 UUID 去重。所有目标与子资源禁止访问私有 Host 端口；设备权限、下载和原生弹窗拒绝。弹出请求提示地址，用户选择在新标签准备后仍需明确恢复。其他回环端口可用于工作区预览；这不是通用 DNS 重绑定或私网防火墙。

可见视图通过全局单一快照控制，隐藏派发不等待导航/获取完成；原生可见性代次拒绝旧显示。审批、设置等弹层出现时撤销网页显示。隐藏失败保留 UNKNOWN，提示清理。WebKit 进程失联显式隐藏并保留身份，不使用 SDK 自动重载默认行为。清理全部浏览器标签入口可核对旧运行代次残留；关闭失败不释放租约，须正常退出应用。清理后旧请求成功/失败均不能恢复旧视图，超时获取也保留请求身份以供放弃和核对。

导航观察读取当前 WK 的地址、标题、加载状态和历史能力，附带原生导航修订号；不直接把旧页面完成事件作用到新导航。当前页无完成确认时以 500ms 续采，30 秒仍无确认转为 UNKNOWN 并隐藏视图，须先关闭后明确恢复。加载失败、关闭失败和超时不得当作可用。

源码已实现不代表通过：本执行器首次打包应用在 AppKit `_RegisterApplication` / `NSApplication init` 阶段 SIGABRT，尚无原生 Browser 操作或截图。原生焦点/快捷键、同/跨工作区存储、弹层遮挡、权限/下载拒绝、页面崩溃、重复操作及窄屏的真实 E2E 均 OPEN。没有换启动入口或重试该失败。
