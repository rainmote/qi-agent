## 本次验证中发现并修复的问题

- MCP stdio 绕过既有沙箱、审批与配置换代竞争；Web 非规范数字域名被 curl 当成本机地址的 SSRF。
- 附件跨工作区引用、工作区根目录被替换为符号链接、超大 base64 正则栈溢出。
- daemon 重新分配 request ID 导致 ACP 等不到完成、文件快照不能收尾；完成早于接纳回包的竞争。
- 相同 command ID 在不同 session 的快照碰撞；读取引用会话不再启动其 worker。
- 等待计划批准时，Clojure/Rust/Web 三层请求通道阻塞批准与取消；取消审批后留下旧提示、硬中断关闭共享会话写入流。
- 旧审批取消后的异常清理误暂停较新的审批；现在清理原子核对提交版本与计划身份。
- goal 暂停/恢复与自动续跑争抢准入，保留状态和执行身份后避免重复派发。
- 停止已死代理时会重新加载 worker，停止/接管路径存在锁顺序冲突；停止现在先禁止恢复，再清理现有进程，并保留无法核实身份的未知写入占用。

故障回归曾出现一次“杀死代理进程后等待停止超时”，后续未稳定复现，因此不能断言该次超时的唯一根因。上述停止语义与锁顺序问题来自代码核对，另有确定性测试验证：代理已死且启动配置无效时仍能停止，不创建新进程；已完成的停止可重复调用；缺失进程身份时不释放未知写入占用。

## 支持范围与未验证项

“已实现”指上述功能已进入代码、默认配置或实际界面，并完成离线验证；不等于与 DeepSeek Harness 的每个实现细节或所有协议扩展完全一致。

- 搜索默认关闭，MCP 默认空服务器；使用外部服务仍需自行配置。没有调用真实模型、收费搜索、真实 MCP 服务或安装外部插件，不声称外部兼容性已验收。
- MCP 为文档列出的协议子集；stdio 仅在明确的本地无沙箱执行世界开放，不偷偷绕过其他执行世界。HTTP 不含 OAuth，通用 MCP 图片/音频尚未投射到模型。
- 文件面板只读；PDF 可预览但不抽取内容给模型，Office 仅元信息/下载。差异是 Web 提交前后的有界文本快照，外部并发修改可能计入，不是撤销或完整仓库审计。
- 后台作业属于 worker，不跨重启恢复，不提供 PTY/交互 stdin。工作流继续使用默认只读研究子代理，不扩大为任意并行写文件系统。
- 插件是受限 Blueprint 与声明式 UI，不执行任意第三方 JS/安装脚本。其他已运行会话不会自动热更新。
- ACP 为 v1；已验证真实 qi daemon 的适配链路，未逐一测试外部 IDE。独立 CLI 没有 daemon 时会明确拒绝调度工具。

本轮没有重启或升级用户正在运行的实例，也没有把源码验收当成当前运行实例已具备这些能力。已有自定义 profile 不会被覆盖；默认 profile 的新能力需要加载本次代码的新 worker，Rust daemon 和 Web 界面改动需要构建后启动对应的新进程。
